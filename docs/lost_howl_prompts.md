# LOST HOWL — сюжетное ядро: промпты и минимальная встройка

Канон дизайна (2026-09). Этот документ заменяет «вокзальный» слой `docs/story_world_manifest.md`
и `docs/story_cassette_design.md` в части рамки повествования: те остаются историей, здесь —
действующее.

**Рамка одной строкой:** бот целиком = видеомагнитофон **LOST HOWL**, собранный из хлама.
У него нет своего мира и своей стаи. Раз в месяц кто-то (хранитель) ставит в лоток кассету —
фанфик-продолжение по миру «Lost Dogs: The Way» (стая псов ищет дом в разрушенном городе).
Плеер проигрывает плёнку, игроки голосуют **один из трёх черновиков кадра**, и по закону дня
(большинство / меньшинство / медиана) движок решает, какой кадр «уцелел». Проигравший черновик
не исчезает — его последствия остаются в тексте следующих дней, как шрам на плёнке.

**То, что промпты не могут менять (жёсткая рамка):**
- Голосование ровно 3 варианта (`position 0/1/2`). Закон дня и энтропию считает движок
  `app/rounds/…` из TON — кассета пишет только режиссёрскую метку `rule_hint`, не закон.
- Одна кассета = ровно один календарный месяц (28–31 день, день = день месяца). Вне своего
  месяца кассета молчит: движок живёт шаблоном (fail-open), кривая кассета не роняет игру.
- Следующую кассету на месяц выбирает хранитель в `/panel` (`STORY_CASSETTE_NEXT_KEY`).
- Дистрибуция $Gram (pool 95% / лидерборды 2%+0,5% / Фонд Стаи 1% / хранитель 0,5% / рефераль
  1%), очки, лидерборды — вне сюжейного слоя. Сюжет их не упоминает, не обещает, не отыгрывает.
- Ветвление сюжета — только через «перемотку» (см. §2), максимум 2–4 переключателя на месяц.
  Никакого дерева 31×3.

## 1. Контракт кассеты (зеркало `app/story/schema.py` — поддерживать 1:1)

```
Cassette:
  cassette_id: str            # имя плёнки
  month: "YYYY-MM"            # ровно месяц по календарю
  title: str
  logline: str | None
  attribution: str | None     # клеймо плёнки: «фанатская плёнка по мотивам …»
  switch: list[Fork]          # 0–4 перемотки; по умолчанию — без ветвлений
  days: list[Day]             # главная дорога (main): день месяца, day_index 1..N подряд

Day:
  day_index: int              # день месяца
  station: str                # место сцены (кадр)
  chapter_title: str          # ≤ 300
  chapter_text: str           # сама сцена (голос плёнки)
  hook_text: str | None       # ≤ 700 — «царапина плёнки»; всплывёт в следующей кассете
  rule_hint: "any"|"majority"|"minority"|"median"   # режиссёрская метка, не закон
  cards: [Card]               # ровно 3, position 0/1/2 без дублей
  tie_note: str | None        # ≤ 200

Fork (перемотка, SwitchModel):
  to: str                     # имя дороги, ≤ 32
  at_day: int                 # ≥ 2: первый день дороги `to`
  winner: 0|1|2               # чья карта уцелела в день at_day-1, чтобы включить дорогу
  days: list[Day]             # день месяца от at_day до N подряд (это и есть дорога `to`)

Card:
  position: 0|1|2
  title: str            # ≤ 120
  description: str
  consequence: str      # «шрам плёнки», если карта проиграет
  tag: "care"           # метка карты (шаблон движка)
  image_path: ""        # необязательно
```

**Бюджет режиссуры:** по месяцу ожидается ≈ N/3 дней на каждый из трёх законов, толеранс ±2
(нарушение = warning, не ошибка).

**Стоп-слова (эвристика по подстроке в нижнем регистре, совпадение = кассета отвергнута):**
финансы и официальность: `woof`, `notcoin`, `$not`, `$bones`, `binance`, `bybit`, `okx`,
`airdrop`, `токен`, `инвестици`, `доход`, `заработ`, `прибыль`, `памп`, `скам`, `криптобирж`,
`сиквел`, `официальн`. Названия мира Lost Dogs (Догтаун, мутагены, имена персонажей) —
**разрешены**: это открытый неофициальный фанфик.

## 2. Ветвление «перемотка» (ответ на «выбор влияет на следующие дни» без 31×3)

- Кассета несёт **главную дорогу** `days` и 0–4 **перемотки** (`switch`).
  Плёнка обычно идёт по `main`; дороги сходятся к финалу месяца.
- Перемотка `{winner, to, at_day}`: **если движок объявил победителем дня
  `at_day - 1` карту `winner` (0/1/2), то с дня `at_day` и до конца месяца
  играется дорога `to`** (её дни — поле `days` перемотки, day_index = at_day..N).
  Решение честное и только по уже закрытому кадру: победителя кассета
  спрашивает у движка (winner_card раунда по дате opens_at), сам не выдумывает.
- Несколько перемоток каскадятся по датам: учитывается последняя, сработавшая
  на текущий день. Перемотки независимы — каждая смотрит только на победителя
  движка в свой день решения.
- Реализация без правки движка: активная дорога вычисляется в `app/story/bay.py`
  при рендере дня из базы (уже закрытые раунды). `apply_switches`/отдельного ключа
  `WatcherState` НЕ нужно — движок о ветвлении по-прежнему не знает (fail-open:
  победителя нет / раунда нет / сбой расчёта дороги → играем `main`).

Даже без `switch` каждый день связан с выбранным черновиком через `consequence`: проигравшие
варианты отзываются в тексте следующих дней. Это и есть «простой» способ сделать месяц цельным.

## 3. Промпт А — «Сюжетное ядро» (продюсер/проигрыватель кассет)

> Роль: доработай сюжетное ядро — модуль `app/story/` (схема-контракт + проигрыватель),
> который принимает кассеты и крутит их по месяцу, — **не трогая игровой движок**.
>
> **Жёсткая рамка (не меняем):**
> - Голосование ровно 3 варианта (`position 0/1/2`). Закон дня (majority/minority/median) и
>   его энтропию считает движок `app/rounds/…` из TON: ядро подставляет главу и три карты
>   поверх честного payload движка (точка встройки — `_plan_and_render` в `app/story/bay.py`).
> - Одна кассета = один календарный месяц, `day_index = день месяца`, кассета активна только
>   когда `month` файла == текущему месяцу. Вне месяца и при кривой кассете — fail-open:
>   движок играет шаблоном, игра и стейки не падают.
> - Следующую кассету месяца выбирает хранитель в `/panel` (`STORY_CASSETTE_NEXT_KEY`);
>   при перекрытии нескольких кассет одного месяца побеждает выбранная, иначе первая по
>   алфавиту.
> - Дистрибуция $Gram, лидерборды, Фонд, рефералка — вне сюжетного слоя.
> - Ветвление — только «перемотка»: контракт `tracks`/`track`/`switch` из §2 этого документа.
>   Не более 2–4 switch на месяц; все дороги сходятся к финалу.
>
> **Контракт кассеты** — ровно как в §1 (поля, лимиты, 3 карты с position 0/1/2, бюджет
> rule_hint ±2, стоп-слова). Валидация — `app/story/schema.py`, поддерживай с ним 1:1.
>
> **Что добавить/доработать:**
> - Активную дорогу (`track`) кассеты хранить в `WatcherState` (свой ключ в
>   `app/core/registry.py`); день выбирается по активной дороге.
> - После фиксации результата раунда читать позицию-победительницу (0/1/2) и при наличии
>   `switch` на этом дне записывать новую дорогу. Вызов — одна точка после подсчёта раунда
>   (движок не трогаем).
> - Табу из §1: финансы/официальность — отвергать, названия мира — пропускать.
> - Логи и служебные сообщения ядра — голос LOST HOWL (плёнка, перемотка, PLAY), без шума
>   в стейке и без обещаний.
>
> **Критерий приёмки:** движок не изменился ни на строку (кроме однажды вызываемого
> `install_bay` в `app/main.py` и одной точки вызова `apply_switches`); месяц играется от
> кассеты; ни кривая кассета, ни отсутствие кассеты не валят стейки, очки и лидерборды;
> тесты: валидация дней=календарь, табу, бюджет, fail-open, выбор кассеты через /panel,
> перемотка (победитель → новая дорога → схождение).

## 4. Промпт Б — «Сюжетная кассета» (автор месяца-фанфика)

> Роль: автор кассеты для плеера **LOST HOWL**. Ты фанат, расстроенный тем, что авторы
> «Lost Dogs: The Way» молчат больше полугода, и пишешь неофициальное продолжение вручную —
> одну плёнку на месяц. В ней стая псов с характерами ищет дом в разрушенном городе
> (Догтаун), каждую сцену стая решает голосованием: **один из трёх черновиков кадра уцелеет**,
> остальные оставят шрам в последующих сценах.
>
> **Вход:** месяц «YYYY-MM» (число дней N посчитай по календарю), номер кассеты в серии,
> «царапина» — `hook_text` предыдущей кассеты (обязан отозваться в новой истории).
>
> **Формат вывода:** JSON-файл кассеты строго по контракту §1 (`app/story/schema.py`).
> Прогони файл через валидатор: `ok`, warnings только по бюджету rule_hint.
>
> **Жёсткие правила:**
> - Дней в файле = N календарных, `day_index` подряд 1..N. Каждый день — одна сцена: глава +
>   ровно 3 карты. Карты — три **сюжетно равноправных** черновика одного поворота (не «плохой/
>   средний/хороший», а три разных по смыслу хода). Все должны быть интересными: проигравший
>   не бессмысленный, его `consequence` отзывается в тексте следующих дней («шрам плёнки»).
> - `rule_hint` — режиссёрская метка, не закон: majority — день явного/громкого хода,
>   minority — скрытого/рискованного, median — компромисса. По месяцу ≈ N/3 на каждый (±2).
> - `hook_text` (≤700) — царапина: деталь, которая к концу месяца обретает значение и
>   передаётся следующей кассете. Кассета, не отозвавшаяся на царапину предыдущей, — брак.
> - Тон — тёплый быт апокалипсиса: циничный юмор, характеры, «все псы хорошие, но разными
>   путями». Не хоррор, не слезливая драма; смерть/тоска — только если она растит стаю в
>   пределах месячной арки.
> - Канон дозволен (Догтаун, мутагены, архетипы вожаков), потому что это откровенный
>   фанфик: обязательное поле `attribution` («Неофициальная плёнка по мотивам Lost Dogs:
>   The Way»). **Запрещено:** токены, биржи, airdrop, доход/заработок, слово «официальн»
>   (стоп-слова §1).
> - «Перемотка» — по желанию: 2–4 дня с `switch {winner, to, at_day}`, дороги сходятся к
>   финалу. Без ветвлений тоже можно — тогда цельность месяца держится на `consequence`.
> - Голос LOST HOWL — в меру, только в сильных точках (старт/конец, поворот): «ПЛЕЙ»,
>   потрескивание, шум пустой плёнки на стыке дней. Не ломиться в каждый абзац.
>
> **Самопроверка перед сдачей:** (1) дней = N; (2) 3 карты по контракту; (3) бюджет
> rule_hint ≈ N/3; (4) царапина предыдущей кассеты отозвалась; (5) switch 2–4 и сходятся;
> (6) стоп-слов нет; (7) весь месяц тянет один logline; (8) файл проходит валидатор с `ok`.

## 5. Минимальная встройка (что менять в коде и почему эти изменения — последние)

1. `app/story/schema.py` — контракт кассеты (§1), лимиты, табу, валидация дней =
   календарь; `switch` (перемотки): не более `MAX_FORKS` (4) за месяц, дороги не
   дублируются, дни дороги идут at_day..N подряд, `winner` в 0..2; мягкое
   замечание при отсутствии `attribution`. Методы `road(today_day, winners)`
   и `day_for(today_day, road)` — выбор дня по дороге.
2. `app/story/bay.py` — при рендере дня: активная дорога по победителям движка
   (winner_card раунда по дате opens_at, из БД), день по дороге через
   `cassette.day_for`. Сбой/нет победителя → главная дорога (fail-open).
   Движок и жизненный цикл раундов не меняются — правок вне `app/story/` нет.
3. Тексты бота (профиль, /start, /help, шаблон дня) — голос LOST HOWL (косметика).
4. `app/story/cassettes/*.json` — кассеты-фанфики по промпту Б (пишутся отдельным шагом).

Блокчейн-механики, стейки, очки, лидерборды, редистрибуция $Gram — **не изменяются вообще**.
